# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of QuickCart seriously. If you discover a security vulnerability:

1. **Do not create a public GitHub issue.**
2. Email full vulnerability details, reproduction steps, and impact assessment to:
   **security@quickcart.com**
3. Our security response team will acknowledge receipt within 24 hours and provide an estimated timeline for remediation.

Thank you for helping keep QuickCart safe!
